# Gameplay Quality Warnings

> **Scope:** Design and playtesting warnings only — not a per-change checklist. Apply only when explicitly asked to review design quality.

Linked from [AGENTS.md](../../AGENTS.md) — kept out of the always-loaded surface so it doesn't burn context on sessions that aren't doing design review. Carried over verbatim from Everdawn's list where the warning applies to an action RPG; Everdawn's warnings about party members, writing, and turn-based battle pacing are left out.

**[CRITICAL] No repetitive combat.** Warn when one skill/tactic solves most encounters. Each character must have multiple valid uses; status, defense, setup, and resource control must matter often.

**[HIGH] No shallow progression.** Warn when a system adds complexity without new decisions. Prefer fewer systems with stronger identity. Allow cheap recovery from bad build decisions.

**[HIGH] No dominant exploits or frustrating spikes.** Test as both critical-path and completionist player. Multiple builds and strategies must remain viable.

**[HIGH] Respect player time.** Retries must be quick. Objectives and recent story context must be easy to review. Add save flexibility, cutscene skip, fast travel.

**Ongoing:** If a feature is impressive once but annoying after 20 repetitions, redesign it. If a mechanic only works because it hasn't been solved yet, it isn't strong enough.
